现役：约基奇、文班亚马、亚历山大、布伦森、杜兰特、哈登、东契奇、字母哥、爱德华兹、米切尔、坎宁安、伦纳德
名宿：乔丹、科比、詹姆斯、邓肯、奥尼尔、诺维茨基、基德、库里、贾巴尔、魔术师、伯德、加内特、韦德

## 技能机制要点

- 判定核心：斗地主胜负取决于「先出完手牌」，因此**能改变手牌数量**的技能才有实质收益；仅强化点数或延迟对手的技能天然接近零收益。
- 字母哥、亚历山大使用同类「造犯规」蓄力机制：被对手压牌时 +1 点，满 4 点发动技能并清零，座位旁有平行四边形四格蓄力条可视化。
- 贾巴尔：压牌时单张可当对子使用，系统自动补全另一张牌，补全牌以黄光圈 + 「补」角标标注。

## 平衡性

每星 N=200 × 2 种子的成对对照仿真（持星 vs 无星基线），判定带：Δ≤5pp 失效 / 5~15pp 温和 / 15~35pp 平衡 / >35pp 过强。
当前 10 名新扩展球星全部落在温和或平衡区。
